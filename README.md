# Revenue Dynamics & Market Volatility Analysis  
SQL | BigQuery | Python | Tableau  

## Overview

This project analyzes session-level revenue data extracted from **Google BigQuery (Google Analytics dataset)** to evaluate revenue stability, market dependency, and performance drivers.

The objective was to move beyond descriptive reporting and assess structural revenue risk and efficiency.

---

## Key Business Questions

- Which market is the core revenue driver?
- Which markets show high volatility?
- Is revenue volatility driven by traffic or conversion efficiency?
- How concentrated is revenue among top sessions?
- Does device category impact conversion performance?
- Do engagement metrics (e.g., pageviews) correlate with revenue?

---

## Methodology

- SQL (BigQuery) for data extraction, aggregation, ranking, and volatility measurement
- Revenue volatility measured using standard deviation
- Session ranking to evaluate revenue concentration (Top X% contribution)
- Traffic vs conversion decomposition to identify growth drivers
- Device-level performance comparison
- Validation and exploration in Python
- Executive dashboards built in Tableau

---

## Skills Demonstrated

- Commercial data analysis
- Revenue risk assessment
- Statistical reasoning (volatility as dispersion)
- End-to-end workflow: BigQuery (SQL) → Python → Tableau

This project reflects real-world commercial analytics challenges in digital businesses, where understanding revenue stability, dependency risk, and performance drivers is critical for strategic decision-making.
